# Base de referências UI

11236 referências em 20 macroáreas. 6000 imagens incluídas no repositório, preservando os formatos disponíveis na fonte.
O usuário reduziu o escopo e os downloads restantes foram encerrados.

CSV: UTF-8 com BOM e delimitador vírgula. JSON: metadados e lista records.
Filtre included_in_repository=true para analisar somente imagens presentes. local_path relaciona os metadados ao arquivo; image_sha256 confere os bytes.
Os demais registros mantêm image_url e source_url e usam download_status=not_included_scope_reduced.

O pacote ZIP contém os metadados. Para baixar também as imagens, use Code > Download ZIP no GitHub ou git clone.
A classificação é automática pelo contexto da fonte, sem curadoria visual individual de todas as referências. Direitos das imagens permanecem com seus titulares.
